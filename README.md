# Dev-Connector

A fullstack web application for developers to find and connect with other like-minded developers.

## Features
- User Authentication
- User profiles
- Match requests
- Messaging System

## Tech Stack
- Frondend: React
- Backend: Node.js + Express
- Database: MongoDB
- Authentication: JWT

## Architecture
Client -> Express API -> MongoDB

## Installation Instructions
1. git clone git-repo-url
2. cd dev-connect
3. npm install
4. npm start // in production server
5. npm run dev // in dev stage

# DevConnector

## Problem

Developers often want to find, connect and hang out with like-minded developers.

## Solution

A web platform where developers can connect, hang out and build professional network based on skills and interests.

## Target Users

- Students
- Freelancers
- Open-source contributors
- Any one who wants to connect with others who have the similar skills and interests 

## Core Features
- User authentication
- Allow users to perform CRUD operations on their own profiles
- Feed/Explore Page
- Allow User to Send connection requests
- Allow User to see his/her matches
- Allow user to see their own sent & received connections requests.
- Real-time Chat
